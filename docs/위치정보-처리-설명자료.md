# STARA 위치정보 수집·이용 설명자료

> 위치기반서비스사업 신고 시 "사업의 종류 및 내용 설명자료"로 사용. 실제 코드
> (`src/components/trip/MissionSheet.tsx`, `src/components/map/TmapMapView.tsx`,
> `src/config/index.ts`) 기준으로 작성. 법률 자문이 아니며 제출 전 위치정보지원센터
> (lbsc.kr, 02-588-0185) 사전상담 권장.

## 1. 서비스 개요

STARA는 K-pop 성지순례 웹서비스다. 사용자가 아티스트와 연관된 특정 장소 근처에
실제로 방문하면 "미션 성공"으로 인정하고 스탬프를 지급한다. 이때 방문 여부를
확인하기 위해 사용자 단말의 GPS 좌표를 1회 사용한다.

## 2. 위치정보 수집 방식

| 항목 | 내용 |
|---|---|
| 수집 주체 | 사용자의 웹브라우저(클라이언트). 별도 수집 서버 없음 |
| 수집 기술 | W3C 표준 Geolocation API (`navigator.geolocation.getCurrentPosition`). OS·브라우저가 제공하는 단말 자체 측위 결과만 사용 |
| 위치정보사업자 이용 | 없음. 외부 위치정보사업자로부터 위치정보를 제공받지 않음 |
| 수집 시점 | 사용자가 명시적으로 조작할 때만 — ① 지도의 "내 위치" 버튼 클릭, ② 미션 인증 화면 진입. 상시·백그라운드 추적(`watchPosition`) 미사용, 1회성 조회 |
| 수집 항목 | 위도, 경도 (측위 시점 1회 스냅샷) |
| 측위 옵션 | 고정밀 모드(enableHighAccuracy), 8초 타임아웃 |
| 동의 | 브라우저·OS의 위치 권한 팝업 + 서비스 이용약관상 동의 |
| 미취득 시 처리 | 권한 거부·미지원·타임아웃이면 위치 확인 단계만 건너뛰고 서비스는 정상 진행 (사용자가 영구히 막히지 않도록) |

## 3. 위치정보 이용 방식

- **용도**: 사용자의 현재 좌표와 목표 장소의 고정 좌표 사이 직선거리(Haversine)를
  계산하여, 반경 200m 이내이면 "위치 확인됨"으로 표시한다. (반경 값:
  `GPS_MISSION_RADIUS_METERS = 200`)
- **처리 위치**: 계산은 전적으로 사용자 브라우저 메모리 안에서만 이루어진다.
- **저장**: 하지 않음. 좌표를 파일·DB·쿠키·로컬스토리지에 기록하지 않는다.
- **서버 전송**: 하지 않음. 미션 제출 시 서버로 보내는 데이터는 장소 ID, 장소명,
  사진 URL, 메모, 여행 ID·이름뿐이며 좌표는 포함되지 않는다.
- **제3자 제공·위탁**: 없음.
- **보유 기간**: 페이지를 벗어나거나 브라우저를 닫으면 즉시 소멸(별도 파기 절차
  불필요).

## 4. 위치정보 처리 흐름도

```
[사용자] "내 위치" 또는 미션 인증 버튼 클릭
   │
   ▼
[브라우저/OS] 위치 권한 팝업 → 사용자 허용
   │
   ▼
[단말 GPS] 위도·경도 1회 취득
   │
   ▼
[브라우저 내 연산] 목표 장소 좌표와 직선거리 계산 (서버 미경유)
   │
   ▼
[화면 표시] 200m 이내 → "위치 확인됨" / 초과 → "○○m 떨어짐"
   │
   ▼
[페이지 이탈] 좌표 메모리에서 폐기 — 저장·전송 없음
```

STARA 서버로 위치 좌표가 전달되는 경로는 존재하지 않는다.

## 5. 위치정보 보호조치 (위치정보법 제16조 관련)

- 위치 좌표를 서버·DB에 저장하지 않으므로 서버측 저장·유출 위험을 원천 차단.
- 통신 구간 전체 HTTPS 암호화.
- 위치정보 처리를 위한 별도 시스템·접근권한이 없음(브라우저 내 1회 연산).
- 외부 위치정보사업자와의 연동·수신 경로 없음(단말 자체 측위만 사용).

## 6. 참고: 미션 인증 사진의 EXIF

미션 인증 사진은 Vercel Blob 스토리지에 저장된다. 사용자가 업로드한 원본 사진
파일에는 촬영 위치가 EXIF 메타데이터로 포함될 수 있다. 이를 위치정보 처리로 보는
견해가 있으므로, 신고서에 이 사실을 함께 기재하거나 업로드 시 EXIF를 제거하는
처리를 추가할 것을 권장한다. (코드상 처리 위치: `src/app/api/photo-upload/route.ts`)
