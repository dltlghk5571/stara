# 한/영 장소명·설명 채우기

## 우선순위 (반드시 이 순서로, 절대 건너뛰지 않음)

한국어 장소명을 영어로(또는 반대로) 채울 때, 절대 학습된 지식만으로 추측하지 않는다.
추측한 로마자 표기는 이 프로젝트에서 계속 문제가 됐던 "로마자 표기 추정치" 오류의
직접적인 원인이므로, 아래 순서를 항상 지킨다.

1. **한국관광공사 TourAPI 영문 서비스** — 관광지·문화시설급 장소는 국문 서비스에서 쓴
   것과 동일한 `contentId`로 영문 서비스를 조회해 공식 영문명을 가져온다. 이건 번역이
   아니라 "정부가 공인한 명칭 매칭"이므로 항상 최우선으로 시도한다.
2. **웹 검색(WebSearch)** — TourAPI에 없는 소규모 장소(카페, 굿즈샵, 식당 등)는 그
   장소가 실제로 쓰는 영문 간판·공식 홈페이지·영문 리뷰 표기를 검색해서 확인한다.
   검색 결과마다 표기가 다르면 공식 홈페이지나 지도 서비스(카카오맵/네이버맵) 쪽
   표기를 우선한다.
3. **국립국어원 개정 로마자 표기법** — 위 두 단계에서 아무 근거도 못 찾았을 때만
   최후 수단으로 적용한다. 이 경우 반드시 아래 "표기 근거 기록" 규칙을 따른다.

## 표기 근거 기록 (건너뛰지 말 것)

채운 값이 어느 단계에서 나왔는지 반드시 같이 남긴다. 근거 없이 값만 채우면 나중에
사람이 검수할 때 뭘 다시 확인해야 하는지 알 수 없다.

- TourAPI로 채움 → 그대로 사용. 이미 공식 출처가 있는 것과 동일하게 취급.
- 웹 검색으로 채움 → 참고한 URL을 같이 남긴다. relation_text의 source_url과는
  별개로, "영문명 근거"로 review 큐에 기록.
- 로마자 표기법 적용 → 반드시 review 큐(review_needed.json 등)에
  `"romanization_estimate": true` 같은 플래그와 함께 남긴다. 기존 "알려진 갭"
  목록에 있는 로마자 표기 추정치 항목과 동일한 방식으로 취급한다.

## status 워크플로우와의 관계

이 스킬로 채운 값은 절대 `draft`를 `verified`나 `published`로 자동 승격시키지 않는다.
verified 승격은 사람이 실제 확인 가능한 링크(인터뷰/브이로그/공식 SNS)로 별도 확인할
때만 이루어진다 — 이 스킬은 빈칸을 채우는 것이지 검증 상태를 바꾸는 게 아니다.

## relation_text 번역 규칙

- 사실 기반 문장만 번역한다 (예: "2024년 뮤직비디오 촬영지"). 감정적 표현이나
  추측성 문장("예뻐서" 등)은 원문에 없으면 새로 만들어내지 않는다.
- 직역보다 자연스러운 현지 표현을 우선하되, 고유명사(장소명·아티스트명)는 위
  우선순위로 확정한 표기를 그대로 쓴다 — 문장 번역 과정에서 고유명사를 다시
  의역하거나 바꾸지 않는다.
- source_url이 없는 relation_text는 애초에 번역 대상이 아니다. 출처 검증 게이트가
  먼저 통과해야 번역 단계로 넘어간다.

## 건드리지 않는 것

- place_category는 이미 확정된 6개 대분류(food / shopping / culture / activity /
  landmark_observatory / kpop) 체계를 그대로 쓴다. 번역 과정에서 카테고리를 새로
  판단하지 않는다.
- 아티스트명은 ARTIST_ALIASES / canonical_artist() 결과를 그대로 쓴다.
  예: NCT DREAM·NCT 127 → NCT, (G)I-DLE → I-DLE. 번역하거나 표기를 바꾸지 않는다.

## 출력 형식

- 기존 JSON 스키마의 필드명·구조를 그대로 유지한다 (place_name_ko/en,
  relation_text_ko/en 등). 새 필드를 임의로 추가하지 않는다.
- 여러 건을 한 번에 처리할 때는 도시(city)/owner 단위로 나눠서 처리한다 —
  build_dataset.py / fill_hours.py와 동일한 --city= / --owner= 단위 규칙을 따른다.
- 처리한 건수와, 그중 몇 건이 TourAPI / 웹 검색 / 로마자 표기법 중 어느 단계에서
  채워졌는지 마지막에 요약해서 보고한다.
